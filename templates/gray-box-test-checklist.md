# قائمة فحص النموذج الرمادي (Gray-box) — اختبار المتعة المجردة

> المصدر: القسم السابع، الخطوة 2.

**المبدأ:** جرّد اللعبة في أسبوعها الأول أو الثاني من المؤثرات البصرية المبهرة والعملات والجوائز. إذا لم تكن جلسة الثلاث دقائق ممتعة وهي مجرد أشكال ومربعات بدائية، فلن تنقذها الرسومات أو الجوائز اليومية لاحقاً.

## قبل الاختبار

- [ ] أُزيلت المؤثرات البصرية المبهرة.
- [ ] أُزيلت العملات والجوائز (بما فيها جوائز الدخول اليومي).
- [ ] اللعبة تظهر بأشكال ومربعات بدائية فقط.
- [ ] الجلسة المختبَرة مدتها **3 دقائق**.

## أثناء الاختبار وبعده

| السؤال | نعم / لا | ملاحظات |
|---|---|---|
| هل الجلسة ممتعة وهي مجرد أشكال ومربعات؟ | | |
| هل يرغب المختبِر في جلسة ثانية دون أي جائزة؟ | | |
| هل تتغير القرارات من لحظة لأخرى أم تتكرر بلا تفكير؟ | | |
| هل سبب الخسارة مفهوم فوراً بالعين؟ (انظر `references/04-mobile-ux-game-feel.md` §6) | | |

## القرار

- **الجلسة ممتعة في صورتها المجردة** → انتقل إلى الصقل والاختبار الصامت (`silent-playtest-protocol.md`).
- **غير ممتعة** → أعد تصميم الحلقة الأساسية؛ لا تعالجها بالرسومات أو الجوائز (`references/03-infinite-gameplay.md`، `references/02-psychology.md` §1 عن التدفق).
